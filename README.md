## 这里能做什么？

Mall Wander 没有任务，也不需要“通关”。你可以只是随便逛逛：

- 在 B1 到 5F 之间自由走动，逛 56 家不同类型的店铺
- 坐扶梯，或者搭中央中庭的观光电梯
- 和 21 位主要店铺的店员聊天，听他们的中文配音
- 找张长椅、咖啡店座位或者花园躺椅坐下来，商场里的椅子都能坐
- 看商场从白天慢慢进入日落和夜晚
- 去 3F 的 **TurboKart** 租一辆卡丁车跑圈，挑战最快圈速
- 去 5F 的 **Starlight Cinema**，把自己电脑上的视频放到大银幕上
- 去 5F 西侧的 **Skyline Garden** 看日落、喷泉、温室和夜里的灯笼
- 打开音乐面板听内置 BGM，或者临时导入自己的歌
- 偶尔听到商场广播：叮咚一声，然后是播音员的声音和字幕

这里更像一个可以待一会儿的地方，而不是一张需要完成目标的地图。

## 第一次来，推荐这样逛

**1F 正门 → 中央中庭 → 扶梯上楼 → 3F TurboKart → 5F Starlight Cinema → 5F Skyline Garden**

如果正好接近日落，就在空中花园多待一会儿。等不及的话，按 `M` 打开音乐面板，可以直接把时间拖到傍晚。

## 三个特别值得去的地方

### 🏎️ TurboKart · 3F 西侧

在前台旁边的登记机前按 `E` 租车，倒计时 3、2、1 后出发。

- `W / S`：油门 / 刹车（停住后再按 `S` 是倒车）
- `A / D`：转向。速度越快转向越钝，进弯前记得松油门
- `R`：卡住了就放回赛道
- `E`：下车，回到大堂

从第一次过起点线开始计时，屏幕上方会显示本圈、上一圈和最佳圈速。最佳成绩保存在你的浏览器里，也会出现在前台的排行榜屏上。

赛道上还有三辆电脑车 Mika、Kenta 和 Lena，会自己跑圈、跟车和超车。从后面追上它们时，它们会让出一条路。

### 🎬 Starlight Cinema · 5F 东侧

大堂里有取票机、售票台、小卖部、周边商店、候场区和检票口，里面是一个 **220 座阶梯影厅**。

走到银幕前按 `E`，选择自己电脑上的视频文件，它就会在银幕上播放。声音从银幕方向传来，BGM 自动压低；找个座位坐下，按 `P` 暂停或继续。

视频只在你的浏览器里读取，**不会上传到任何地方**。MP4（H.264）和 WebM 最稳，浏览器不支持的格式会给出提示。

### 🌇 Skyline Garden · 5F 西侧

一个真正可以走出去的室外空间：喷泉广场、草坪和野餐桌、爬藤花架、菜园、温室、看日落的木平台和躺椅。园丁陶爷爷就在育苗台附近，可以和他聊聊。

日落时天空和光线会变暖；夜里灯笼亮起后，又是另一种感觉。

## 操作

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 移动 |
| `Shift` | 跑步 |
| `空格` | 跳跃 |
| 鼠标 | 转动视角（先点击画面） |
| `E` | 互动：聊天、坐下 / 站起、呼叫电梯、选楼层、影院面板、租车 / 下车 |
| `V` | 切换第一 / 第三人称 |
| 滚轮 | 第三人称镜头远近 |
| `M` | 音乐面板（也能调游戏时间、开关商场广播） |
| `P` | 在影厅里暂停 / 继续影片 |
| `R` | 开卡丁车时回到赛道 |
| `L` | 中文 / English |
| `Esc` | 暂停，释放鼠标 |

在电梯轿厢里按 `E` 会打开楼层面板，也可以直接按数字键 `1`–`5` 或 `B` 选层。

## 音乐、广播和时间

- 游戏里的一天大约等于现实中的 20 分钟。天空、太阳、星星、天窗光束和夜灯都会跟着变化。
- 音乐面板里可以拖动时间或暂停时间。时间会保存在浏览器里，下次打开接着走。
- 每隔七八分钟会有一条商场广播；早晨、日落、入夜和影院开场前也各有一条。不想听可以在音乐面板里关掉。
- 店员说话时广播会等一等；在影厅里看电影时不会插播广播。
- 网页版内置的 BGM 是巴赫《哥德堡变奏曲》钢琴录音（Kimiko Ishizaka，CC0 公有领域）。
- 你也可以在音乐面板里导入自己的本地歌曲（也可以直接拖进窗口），和内置曲目一起循环播放。导入的歌只在本次打开期间有效，不会上传。

## 设备与浏览器

- **推荐**：电脑 + 键盘鼠标 + 最新版 Chrome 或 Edge。
- 开发时主要在 Chrome 上测试；Safari、Firefox 等其他浏览器没有充分测试，可能会有小问题。
- 暂时不支持手机和平板（没有触屏操作）。
- 需要浏览器支持 WebGL，并开启硬件加速。

## 常见问题

<details>
<summary><b>打开后没有声音？</b></summary>

浏览器要求先有一次点击才能播放声音。点一下开始界面上的「点击开始」，音乐就会响起来。也可以按 `M` 打开音乐面板看看音量。
</details>

<details>
<summary><b>鼠标被“锁住”了，怎么出来？</b></summary>

点击画面后，鼠标会用来控制视角。按 `Esc` 就能释放鼠标，再点一下画面回到游戏。
</details>

<details>
<summary><b>画面卡顿怎么办？</b></summary>

- 关掉其他占用显卡的网页或程序
- 确认浏览器开启了硬件加速
- 在网址后面加上 `?nofx`，关闭描边和泛光：<https://roycebella-commits.github.io/supermarket/?nofx>
</details>

<details>
<summary><b>第一次打开有点慢？</b></summary>

第一次需要下载模型、贴图和音乐，网速慢时请稍等一会儿。店员模型和配音会在你走近时才加载。
</details>

<details>
<summary><b>进度和设置保存在哪里？</b></summary>

语言、游戏时间、卡丁车最佳圈速、广播开关等都保存在你自己的浏览器里，不需要账号。换浏览器或清除网站数据后会恢复默认。
</details>

<details>
<summary><b>我选的视频和导入的歌会被上传吗？</b></summary>

不会。它们只在你的浏览器里读取和播放，关掉网页就没了。
</details>

<details>
<summary><b>想看英文界面？</b></summary>

按 `L`，或者点开始界面右上角的「中 / EN」。店员的语音是中文，英文界面下字幕会显示英文翻译。
</details>

### 技术栈

Vite · TypeScript · Three.js · Rapier · three-vrm · postprocessing

### 本机运行

推荐 Node.js 24（当前 Vite 需要 Node.js 20.19+ 或 22.12+）。

```bash
npm install
npm run dev
```

然后用 Chrome 打开 <http://127.0.0.1:5173/>。

常用命令：

```bash
npm run typecheck
npm run build
npm run preview
```

### Windows

双击根目录的 `start.cmd`，会启动开发服务器并打开浏览器。

首次运行会自动从 Node.js 官方源下载项目专用的 Node.js 24.21.0，并按锁文件安装 Windows 依赖。运行环境和 npm 缓存保存在 `.runtime/`，不修改系统 PATH，也不需要管理员权限。

- `setup.cmd`：单独配置环境或重装依赖
- 关闭启动窗口或按 `Ctrl+C`：停止服务器
- 构建：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/windows.ps1 -Action build`
- 类型检查：把 `build` 换成 `typecheck`；构建预览换成 `preview`

游戏运行本身不需要 Python、ffmpeg 或本地语音模型，这些只用于重新制作素材。

### 在 macOS 和 Windows 之间换着用

`node_modules` 里有按系统区分的原生依赖。同一个项目文件夹（例如移动硬盘）在两个系统之间来回用时：

- 到 Windows 上：`start.cmd` 会自动发现并重新安装依赖。
- 回到 macOS 上：如果启动时报 `Cannot find native binding`，先运行一次 `npm ci`。

### GitHub Pages

推送到 `main` 后，GitHub Actions 会自动安装依赖、检查类型、构建并更新在线版本。首次发布需要在 `Settings → Pages → Source` 里选择 `GitHub Actions`。

在线版只包含可以公开发布的 BGM，开发者本机使用的商业曲目不在仓库里。

### 调试参数

| 参数 | 作用 |
|---|---|
| `?debug` | 碰撞线框、FPS、draw call、坐标 |
| `?map` | 当前楼层平面图和玩家位置 |
| `?floor=3` | 直接进入指定楼层（`1`–`5`，或 `B1`） |
| `?shop=turbokart` | 传送到指定店铺门口（店铺 id 见 `src/data/mallLayout.ts`） |
| `?view=first` | 第一人称开局 |
| `?nofx` | 关闭描边与泛光 |
| `?testbed` | 加载调手感用的测试场 |
| `?bgmSeek=-5` | BGM 从循环接缝前 5 秒开始，用来听接缝 |

参数可以组合，例如 `?debug&map&floor=5`。浏览器控制台里还有测试钩子 `window.__game`，其中 `window.__game.stats()` 可以查看 draw call、三角形数和渲染用时。

### 性能策略

- 商品、装饰图与夜灯按楼层分组，只渲染当前楼层和相邻楼层
- 商品使用实例化；静态建筑按楼层和材质合并；招牌按楼层打包成图集
- 店员走近才加载，按距离、楼层和视野裁剪，身体网格合并
- 电脑卡丁车只在玩家位于 2F–4F 时运行
