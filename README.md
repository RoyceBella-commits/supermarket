# 商场漫游 · Mall Wander

> 一个可以直接在浏览器里慢慢逛的卡通商场。

**B1 + 1F–5F、56 家店、会说话的店员、扶梯与观光电梯、昼夜变化、空中花园、电影院、卡丁车，以及一堆不一定“有用”但很适合闲逛的小互动。**

## ▶ 立即游玩

### [点击这里进入 Mall Wander](https://roycebella-commits.github.io/supermarket/)

无需安装，无需账号，打开网页即可开始。

推荐使用 **电脑 + 键盘鼠标 + 最新版 Chrome**。Safari 可以正常游玩；如果设备性能较弱或后处理造成掉帧，可以在网址后加上 `?nofx` 关闭描边与泛光。

---

## 这里能做什么？

Mall Wander 没有强制任务，也不要求你“通关”。

你可以只是随便逛逛。

- 在 B1 到 5F 之间自由探索，逛不同类型的店铺
- 坐扶梯，或者搭中央中庭的观光电梯
- 和 21 位主要店铺的店员聊天，听他们的中文配音
- 找张长椅、咖啡店座位或者花园躺椅坐下来
- 等商场从白天慢慢进入日落和夜晚
- 去 3F 的 **TurboKart** 租一辆卡丁车跑圈
- 去 5F 的 **Starlight Cinema**，把自己电脑上的视频放到商场银幕上播放
- 去 5F 西侧的 **Skyline Garden** 看日落、喷泉、温室和夜间灯笼
- 打开音乐面板，听内置 BGM，或者临时导入自己的本地音乐
- 偶尔听到商场广播，以及和时间、影院场次有关的特别播报

这里更像一个可以待一会儿的地方，而不是一张需要完成目标的地图。

---

## 第一次来，推荐这样逛

如果你不知道先去哪，可以试试这条路线：

**1F 正门 → 中央中庭 → 扶梯上楼 → 3F TurboKart → 5F Starlight Cinema → Skyline Garden**

如果正好接近日落，5F 西侧的空中花园会更适合停一会儿。

商场里的昼夜会持续变化：一个完整游戏日大约 20 分钟。天空、太阳、星星、天窗光束、室外亮度以及夜间灯光都会随时间改变。

---

## 商场里有什么？

整个商场是一个 B1 + 1F–5F 的线形综合体：

- **21 家主要店铺**：有原创店员、对话和配音
- **35 家配角店铺**：有完整店面与内部布置
- 中央中庭、东西扶梯挑空和观光电梯
- 公共长椅、餐饮座位、吧台凳、休息沙发、试鞋凳等可坐座位
- 5F 室外空中花园
- 5F 大型电影院
- 3F 室内卡丁车场

店铺招牌、角色和大量装饰内容都是为这个项目原创制作的。

---

## 三个特别值得去的地方

### Skyline Garden · 5F 西侧

一个真正可以走出去的室外空间。

这里有喷泉广场、草坪、野餐桌、爬藤花架、菜园、温室、木平台和躺椅。园丁陶爷爷会待在育苗台附近。

日落时天空和光线会变暖；夜里灯笼亮起后则是另一种感觉。

### Starlight Cinema · 5F 东侧

影院包含大堂、取票区、售票台、小卖部、周边商店、候场区、检票口和一个 **220 座阶梯影厅**。

走到银幕前按 `E`，可以选择自己电脑上的视频文件播放。

视频只在你的浏览器本地读取，**不会上传到服务器**。

支持浏览器可直接播放的格式，例如 MP4/H.264、WebM。播放期间 BGM 会自动降低音量，按 `P` 可以暂停或继续。

### TurboKart · 3F 西侧

在登记机前按 `E` 租车，倒计时结束后就可以开。

- `W / S`：油门 / 刹车与倒车
- `A / D`：转向
- `R`：卡住时回到赛道
- `E`：下车

赛道会记录本圈、上一圈和最佳圈速，最佳成绩保存在浏览器中，也会出现在前台排行榜上。

赛道上还有三辆电脑车，会自己跑圈、跟车和超车。

## 操作

| 按键 | 作用 |
|---|---|
| W A S D / 方向键 | 移动 |
| Shift | 跑步 |
| 空格 | 跳跃 |
| 鼠标 | 控制视角 |
| E | 互动：聊天、坐下、呼叫电梯、选层、影院、租车等 |
| V | 第一 / 第三人称切换 |
| 滚轮 | 调整第三人称镜头距离 |
| M | 音乐面板 / 游戏时间 / 商场广播 |

| L | 中文 / English |
| Esc | 暂停 / 释放鼠标 |

点击游戏画面后，浏览器会锁定鼠标以控制镜头；按 `Esc` 可释放。

## 音乐、广播和时间

商场会自己“生活”。

- 游戏里一天约等于现实 20 分钟
- 音乐面板可以拖动或暂停游戏时间
- 时间会保存在浏览器里，下次打开可以接着走
- 商场每隔一段时间会播放广播
- 某些广播与早晨、日落、入夜和影院场次有关
- 店员说话或影院播放时，音乐和广播会主动避让

公开网页版使用可公开发布的 BGM。

你也可以临时导入自己的本地歌曲加入播放列表；文件只留在当前浏览器会话里，不会上传。

## 关于角色和店员

默认玩家角色与主要店铺店员都是原创 Q 版 VRM 角色。

店员会在玩家靠近时看向玩家，按 `E` 可以开始对话，再按一次继续下一句。语音为中文，英文界面会显示英文字幕。

玩家可以在第一人称和第三人称之间随时切换。

### Windows

双击根目录的 `start.cmd` 可启动开发服务器并打开浏览器。

首次运行会自动从 Node.js 官方源下载项目专用的 Node.js 24.21.0，并按锁文件安装 Windows 依赖。运行环境和 npm 缓存保存在 `.runtime/`，不修改系统 PATH，也不需要管理员权限。

- `setup.cmd`：单独配置环境或重装依赖
- 关闭启动窗口或 `Ctrl+C`：停止服务器
- 构建：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/windows.ps1 -Action build`
- 类型检查：把 `build` 换成 `typecheck`
- 构建预览：把 `build` 换成 `preview`

游戏运行本身不需要 Python、ffmpeg 或本地语音模型；这些只用于重新制作素材。

### 性能策略

- 商品、装饰图与夜灯按楼层分组，只渲染当前楼层及相邻层
- 商品使用实例化
- 静态建筑按楼层和材质合并
- 招牌按楼层生成图集
- 店员靠近后才加载，并按距离、楼层和视野裁剪
- 店员身体网格合并
- 电脑卡丁车只在玩家位于 2F–4F 时运行

`window.__game.stats()` 可查看 draw call、三角形数和渲染用时。
