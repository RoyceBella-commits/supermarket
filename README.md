# 商场漫游 · Mall Wander

在浏览器里自由逛的卡通商场（Vite + TypeScript + Three.js + Rapier + three-vrm）。规划见 `PLAN.md`（不在仓库里）。

- 已完成：阶段 1（骨架、灰盒、第一人称、音乐系统）、阶段 2（卡通渲染、VRM 角色、第三人称）、阶段 3（扶梯、观光电梯）、阶段 4（店员与对话、店内布置、座位、店铺 logo、装饰插图）、阶段 5（昼夜循环、天窗光束、空中花园、影院、卡丁车、商场广播、性能优化）。
- 商场：136 × 52 m 的“哑铃型”线形商场，B1 + 1F–5F。两端是主力店，中间 100 m 商业街，有中央中庭和东西两个扶梯挑空。
- 店铺：21 家主要店（有店员、台词和配音）+ 35 家配角店（只有店面和内部布置）。

## 在线游玩与发布

[点击这里直接游玩商场漫游](https://roycebella-commits.github.io/supermarket/)

项目通过 GitHub Pages 提供浏览器直接游玩的版本。推送到 `main` 后，GitHub Actions 会自动安装依赖、检查类型、构建并更新网页。

首次发布需在仓库 `Settings → Pages → Source` 中选择 `GitHub Actions`。工作流自动读取网页的子目录路径，角色、贴图、配音和音乐都能从正确位置加载。

公开构建仅使用公开版 BGM 歌单；本机商业音乐不上传、不发布。运行时推荐使用带键盘和鼠标的电脑浏览器。

## 本机运行

推荐 Node.js 24。当前 Vite 需要 Node.js 20.19+ 或 22.12+。

### Windows 本机运行

双击根目录的 `start.cmd`，会启动开发服务器并打开浏览器。首次运行自动从 Node.js 官方源下载项目专用的 Node.js 24.21.0（校验 SHA-256），并按锁文件安装 Windows 依赖；需要联网。运行环境和 npm 缓存保存在 `.runtime/`，不修改系统 PATH，不需要管理员权限。

- `setup.cmd`：单独配置环境或重装依赖。
- 关闭启动窗口或按 `Ctrl+C`：停止服务器。
- 构建验证：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/windows.ps1 -Action build`。
- 类型检查：同上，将 `build` 换成 `typecheck`；构建预览则换成 `preview`。
- 移动硬盘热更新异常时，在 PowerShell 中先执行 `$env:VITE_POLL='1'`，再运行 `.\start.cmd`。

游戏运行不需要 Python、ffmpeg 或本地语音模型；这些仅供重新制作素材使用。

### 已安装 Node.js/npm 的环境

```bash
npm install
npm run dev
```

然后用 Chrome 打开 <http://127.0.0.1:5173/>，点击画面开始。

- `npm run typecheck`：类型检查
- `npm run build`：类型检查 + 打包到 `dist/`；`npm run preview` 预览打包结果

> 项目放在 exFAT 移动硬盘上：`.npmrc` 关掉了 npm 的 bin 链接（exFAT 不支持符号链接），所以脚本直接用 `node node_modules/...` 调用工具。
> 改了文件页面没自动刷新时，用 `VITE_POLL=1 npm run dev` 改成轮询监听。

## 调试参数

| URL 参数 | 作用 |
|---|---|
| `?debug` | 碰撞线框、FPS、draw call 数、坐标 |
| `?map` | 当前楼层的平面图和玩家位置 |
| `?floor=3` | 直接传送到 3F 中庭旁 |
| `?shop=kumo` | 传送到某家店门口（id 见 `src/data/mallLayout.ts`） |
| `?floor=B1` | 地下超市前厅（`?floor=1`–`5` 对应 1F–5F） |
| `?view=first` | 开局用第一人称 |
| `?nofx` | 关闭描边和泛光（排查画面问题或低配电脑） |
| `?testbed` | 只加载调手感用的测试场（台阶、坡道、楼梯、矮墙） |
| `?bgmSeek=-5` | 内置 BGM 从循环接缝前 5 秒开始，用来听接缝；正数表示从第几秒开始 |

参数可以组合，例如 `?debug&map&floor=5`。浏览器控制台里有测试钩子 `window.__game`。

## 昼夜和天气

- 游戏里一天约 20 分钟（真实时间）：早晨、正午、日落、夜晚依次变化，天空、太阳、星星、室外亮度跟着变；中庭天窗下有随太阳方向倾斜的光束，日落时发橙，夜里消失。
- 入夜后空中花园的灯笼、外立面的楼层灯带和正门筒灯亮起来。
- 音乐面板（M）里可以拖动时间、暂停时间。游戏时间记在浏览器里，下次打开接着走。

## 空中花园、影院、卡丁车

- **Skyline Garden（5F 西侧，室外）**：喷泉广场、草坪和野餐桌、爬藤花架下的长桌、菜园和温室、看日落的木平台和躺椅，椅子都能坐；园丁陶爷爷在育苗台前，可以对话。日落和夜里灯笼亮起时最好看。
- **Starlight Cinema（5F 东侧）**：大堂（取票机、售票台、小卖部、周边商店、等候区、检票口）+ 一个阶梯大影厅（220 个座位都能坐）。走到银幕前按 E 打开面板，选一个本机视频文件就会在银幕上播放（只在本机播放，不上传）。支持浏览器能直接播的格式（MP4/H.264、WebM 等），不支持的会提示。声音从银幕方向传来，在影厅里看片时 BGM 自动压低，按 P 暂停 / 继续。
- **TurboKart（3F 西侧）**：玻璃围起来的大堂（前台、头盔墙、排行榜屏、Pit Café、颁奖台），外面是绕大堂一圈的 M 形赛道。在登记机前按 E 租车，倒计时 3、2、1 后出发：W / S 油门和刹车（停住后 S 是倒车），A / D 转向，高速时转向变钝，进弯前松油门；撞到轮胎墙会掉速，卡住按 R；按 E 下车回到大堂。从第一次过起点线开始计时，屏幕上方显示圈数、本圈、上一圈和最佳圈速，最佳成绩保存在浏览器里，也会上前台的排行榜屏。赛道上还有三辆电脑车，会跟车和超车。

## 商场广播

- 每隔 7–9 分钟（真实时间）播一条：上行“叮咚”提示音 → 广播员语音（屏幕上方有字幕，跟界面语言）→ 下行提示音，播放时 BGM 压低。
- 另外在游戏时间 7:00（早安）、17:15（看日落）、19:30（入夜）和影院开场前（10:45、14:45、18:45）各有一条。拖动时间滑块跳过去的不算。
- 店员正在说话时会等一等；在影厅里看电影时不播。音乐面板里可以关掉广播。
- 广播员配音同样由 Qwen3-TTS VoiceDesign 生成（`announcer-01`–`12`），台词在 `src/data/announcements.ts`。

## 扶梯和电梯

- 扶梯在东西两个挑空里，北侧上行、南侧下行（入口扶手端有绿色方向牌），1.2 m/s，站上去自动走，也可以边走边乘。东侧扶梯一直通到 B1。
- 观光电梯在中央中庭南缘，停 B1–5F：门口按 E 呼梯，进轿厢按 E 选楼层。

## 店员和对话

- 21 家主要店各有一位店员（原创 Q 版 VRM，`public/models/staff/<店铺 id>.vrm`），大多站在收银台后面。靠近时会转头看你，按 E 对话，再按 E 下一句，台词循环；走开对话框自动关闭。
- 台词在 `src/data/npcDialogue.ts`：语音是中文，英文界面下字幕显示英文翻译。
- 配音由本机 Qwen3-TTS VoiceDesign 离线生成到 `public/audio/voice/`（流程见 `tools/voice/README.md`）。说话时 BGM 自动压低；某句没有配音时只显示字幕。

## 座位

商场里的椅子都能坐：公共长椅、咖啡店和餐厅的椅子、美食广场、吧台凳、店内休息沙发、试鞋凳等。走到椅子旁按 E 坐下，按 E 或移动 / 跳跃站起来。

## 店内布置和装饰

- 店内家具和商品按品类模板生成（`src/world/interiors/templates/`），依据 `docs/interior-references.md`（日本、美国真实店铺的照片和报道整理出的布局规则）：门口留空、主通道 ≥ 2.4 m、主力店 T 形动线、后墙有一眼能看到的“磁石”、收银台带背柜、后墙一角员工门，每类店做出 3–5 个最好认的细节。
- 开发模式下会自动检查店内布置：家具重叠、占了预留通道、座位或店员走不到，有问题会和布局问题一起显示在左上角。
- 店铺招牌是代码画的原创 logo（品类图标 + 字标，`src/world/logos.ts`）。
- 海报、菜单板、书封、盲盒卡、积木盒、美食图、电影海报、影院主视觉、卡丁车横幅等 25 张无文字插图由 Codex 生成（`tools/decor/`，见 `CREDITS.md`），游戏运行时按店铺加载。

## 角色模型

- 默认角色 `public/models/player.vrm` 由 `tools/vrm/` 的脚本用代码生成（原创 Q 版，见 `tools/vrm/README.md`）。
- 换成自己的角色：把任意 VRM 文件（VRoid Studio 导出的也行，0.x / 1.0 都支持）命名为 `player.vrm` 放到 `public/models/` 覆盖即可。游戏会按模型身高自动调整碰撞体和第一人称眼睛高度。
- 动画是代码驱动的（待机、走、跑、跳），不需要动画文件。

## 背景音乐

- **本机版**：`public/audio/bgm/playlist.local.json` + `local/reminiscence.m4a`。商业曲目，只在本机使用，已加入 `.gitignore`。
- **公开版**：`public/audio/bgm/playlist.json` + `public/*.m4a`，Open Goldberg Variations 里的 4 首钢琴曲（CC0），见 `CREDITS.md`。
- 游戏优先读本机版歌单，没有就用公开版，再没有就用代码合成的占位音乐。
- 音乐面板里可以一次导入多首本地歌曲（也可以拖进窗口），和内置曲目一起按列表循环 / 单曲循环 / 随机播放。导入的歌只在本次打开期间有效，文件不会上传到任何地方。
- 内置曲目的循环点和响度由 `tools/audio/` 的离线脚本生成，说明见 `tools/audio/README.md`。

## 性能

- 商品、装饰图、夜灯按楼层分组，只画玩家所在楼层和上下相邻层；商品用实例化（每家店一组方块 + 一组圆柱）。
- 静态建筑按（楼层，材质）合并；招牌按楼层打包成图集，每层一个网格。
- 店员模型靠近才加载；不在画面里、太远或隔层较远的店员不画；每个店员的身体网格合并成一个（调色板贴图）。
- 电脑卡丁车只在玩家位于 2F–4F 时运行。`window.__game.stats()` 可以看 draw call、三角形数和渲染用时。
